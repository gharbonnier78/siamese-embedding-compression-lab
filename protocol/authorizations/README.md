# Scientific access authorizations

This directory contains narrow, machine-readable governance authorizations that are
separate from frozen scientific protocols.

An authorization may permit an otherwise-forbidden evidence access for one named execution
step after its prerequisites are reviewed. It MUST NOT silently mutate the statistical
method, promote a scientific claim, or broaden downstream study scope.

For Study 0, `study_0_historical_reanalysis_v0.2.2.yaml` permits historical score access
only for the frozen `corrected_study_0_reanalysis` step after review and merge. The frozen
known-truth coverage contract remains unchanged and continues to record that its own
execution did not permit historical score access.
