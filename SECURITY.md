# Security and responsible disclosure

This repository is an exploratory research implementation, not a production biometric
system or security control.

Do not submit personal biometric data, credentials, private datasets or operational
system details in an issue. For a vulnerability that could create practical security or
privacy impact, contact the repository owner privately through GitHub before publishing
technical details. Ordinary correctness and reproducibility defects may be reported as
public issues.

Only the latest tagged release is considered for maintenance. No result in this
repository constitutes certification, operational acceptance or regulatory compliance.
